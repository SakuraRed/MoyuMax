# 里程碑 3：真实安装执行器与原子实例提交

## 用户结果

用户确认安装后，任务中心展示真实阶段、已知总量和已完成字节。MoyuMax 下载并校验 Minecraft、资源对象、Fabric 与 Azul JDK，在任务专用暂存区完成准备，最后原子发布一个可启动实例。网络中断或应用退出后可继续，不会出现半完成实例。

## 实现范围

1. 统一任务协调器限制同时执行的安装任务，并共享下载并发上限。
2. HTTP Range 续传；来源忽略 Range 时仅清理对应未完成文件并从头下载。
3. SHA-1/SHA-256 与大小校验；可信值不匹配时禁止提交。
4. 展开 Mojang 资源索引，按内容哈希在全局存储中去重资源对象。
5. 解析 Windows x64 原生库规则，下载并安全解包本机原生库。
6. 解析 Fabric Maven 坐标与校验值，将兼容 Profile 纳入同一安装快照。
7. 安全解包 Azul JDK，拒绝绝对路径、父目录穿越、符号链接和解压炸弹。
8. 创建完全隔离的实例可变目录和版本化运行时清单。
9. 共享文件与 Java 可先提交为校验缓存；实例目录与数据库可启动记录必须补偿式原子提交。
10. 失败保留可续传暂存，任务显示用户语言错误；重试不改变原计划。

## 不变量

- 未校验文件永远不能进入受管共享存储。
- 下载失败不得覆盖已有共享文件。
- 实例目录发布与数据库 `ready` 记录要么同时成功，要么恢复到未发布状态。
- 运行中任务重启后不自动联网，必须先取得用户恢复确认。
- 下载器只写入任务暂存区和经过验证的受管目标，所有相对路径经过组件级校验。
- Java 身份仍由“发行版、完整构建、架构”唯一约束。
- 未知总量不得显示伪造百分比。

## 后续衔接
