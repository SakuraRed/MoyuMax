# 里程碑 28：自定义背景与纯数据主题包

## 目标

用户可以在默认主题之外选择纯色或本地图片作为界面背景，也可以导入纯数据 JSON 主题包改变配色；主题包绝不包含 CSS、脚本、布局或远程资源；减少动画或隐藏窗口时背景即时降级释放。

## 范围

1. 自定义背景：`ui_background` 持久化（default / color #rrggbb / image 本地图片），外观设置区选择；图片经对话框选择本地文件（png/jpg/webp，≤ 8 MiB），读取后以 data URL 渲染并压暗保证可读性。
2. 纯数据主题包：`{formatVersion, name, author, colors}` JSON；校验拒绝非 JSON、未知字段、非颜色值与任何 URL 形式字符串；导入后作为变量覆盖叠加到当前明暗主题之上；可一键移除回到默认。
3. 降级语义：窗口隐藏（托盘）或减少动画开启时，图片背景不渲染（回到纯色底）；高对比开启时忽略主题包配色（保证对比语义）。
4. 外观设置区：背景类型选择、颜色输入、图片选择/清除、主题包导入/移除与状态说明（主题包为纯数据、不会执行代码）。

## 非目标

- 不实现视频/动画背景（资源治理另行评估）。
- 不实现主题包分享目录或在线下载。
- 不开放任意 CSS 注入。

## 安全不变量

- 主题包与图片绝不引用远程资源；导入校验拒绝任何 URL。
- 主题包不可覆盖安全关键文案与布局，只允许配色变量。
- 隐藏窗口与高对比/减少动画时背景必须降级。

## 验证

- Rust BDD：主题包解析与拒绝（非 JSON、未知字段、URL、非颜色）、背景设置持久化与边界、图片类型/大小校验。
- Playwright：纯色/图片/主题包应用与移除、减少动画降级、高对比忽略主题包、960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
