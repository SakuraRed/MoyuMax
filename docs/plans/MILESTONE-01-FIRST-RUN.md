# 里程碑 1：首次运行垂直切片

## 用户价值

首次启动 MoyuMax 时，用户可在完全离线状态完成语言、数据位置和隐私选择；选择以事务写入本地数据库。再次启动时直接进入首页空状态，不重复显示引导。

## 范围

- Tauri 无边框窗口和 Svelte 声明式 mockup 应用外壳。
- 三步首次运行引导与完成汇总。
- 默认值：简体中文回退、安装目录下 `data`、遥测关闭、更新检查开启但只提示、NAT 检测关闭、实例隔离开启。
- SQLite schema 初始化和一次事务持久化。
- 首页空状态与“安装第一个游戏”入口占位；本里程碑不伪装成已经能够安装游戏。
- 浏览器开发适配器、Rust 行为测试、TypeScript 状态测试和桌面运行验证。
- 960×600、150% 和 200% 缩放下执行重叠与溢出检查。

## 非范围

- 游戏清单、下载、Java 安装、账户登录和任务执行。
- 托盘常驻、安装器、签名和自动更新实现。
- 三种语言的完整界面翻译；本里程碑只保存选择并建立接口。

## 验收

- `features/ui/first-run.feature` 中的场景均有自动测试映射。
- 新数据库返回 `requiresOnboarding=true`。
- 完成引导后同一数据库返回 `requiresOnboarding=false`，选择值保持一致。
- UNC/SMB 路径被拒绝，数据库仍保持未完成状态。
- 浏览器开发模式可以从引导进入首页空状态。
- Tauri Debug 构建成功并可启动。
- 形成 Release 冷启动和内存的第一份基线；Debug 或浏览器数据不能代替 Release 基线。
