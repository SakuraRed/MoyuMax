# 里程碑 20：账户入口（离线与 Authlib Injector 外置登录）

## 目标

用户可以创建本地离线账户、通过 Authlib Injector（含 LittleSkin 快捷选项）登录外置账户，管理默认账户并刷新会话；启动游戏使用默认账户的真实身份；Microsoft 登录在应用注册完成前不提供入口，也不伪装可用。

## 范围

1. 账户模型：schema v15 `accounts` 表（离线与外置统一模型：kind、用户名、玩家 UUID、服务器地址、令牌、默认标记、会话状态）；令牌只保存在本地数据库，不进入日志、诊断或前端序列化。
2. Yggdrasil 客户端：authenticate / refresh / validate 三个端点，LittleSkin 预设地址与自定义 Authlib Injector 地址；网络与凭据错误分类可读。
3. 账户操作：创建离线账户（3–16 位 ASCII 规则沿用启动校验）、外置登录（只存令牌不存密码）、设为默认（唯一）、移除、刷新会话（失败标记过期，启动时提示重新登录）。
4. 启动接入：`start_instance` 使用默认账户；离线账户沿用离线 UUID 派生；外置账户启动前尽力刷新，刷新失败且令牌失效时拒绝启动并说明重新登录。
5. 前端：设置页新增账户管理区（列表、添加离线、添加外置、设为默认、刷新会话、移除）；首页启动显示默认账户名；Microsoft 入口仅以说明文字呈现"应用注册进行中"。

## 非目标

- 不实现 Microsoft 登录（受应用注册进度限制）。
- 不实现密码保险库与主密码（4.5 的独立后续项）；密码只用于当次登录，绝不落盘。
- 不实现统一通行证（同一 Yggdrasil 协议，预设地址后续补）。

## 安全不变量

- 密码只在登录请求中使用，绝不写入数据库、日志或诊断。
- 令牌不序列化到前端；账户列表只含非敏感字段。
- 外置登录地址必须 https（本机测试环境除外）；不跟随到其他主机的重定向。
- 离线账户启动不伪装正版身份。

## 验证

- Rust BDD：离线账户创建与校验、外置登录成功与失败分类、令牌刷新、默认唯一、移除、会话过期标记、启动身份解析、fixture 服务端。
- Playwright：账户列表、添加两种账户、默认切换、刷新、移除、Microsoft 占位说明、960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
