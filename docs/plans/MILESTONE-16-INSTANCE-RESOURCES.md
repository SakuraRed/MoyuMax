# 里程碑 16：实例资源内容管理（资源包/光影/数据包）

## 目标

用户可以为实例导入本地资源包、光影包和数据包文件，按类型查看清单并切换启用状态；所有写入具备事务、原子提交或可验证补偿路径，实例之间完全隔离。

## 范围

1. 资源类型模型：`resourcepack` → `.minecraft/resourcepacks/`、`shader` → `.minecraft/shaderpacks/`、`datapack` → `.minecraft/saves/<世界>/datapacks/`。
2. 世界只读列举：扫描 `.minecraft/saves/` 下含 `level.dat` 的目录，供数据包选择目标世界。
3. 本地文件导入（`.zip` / `.jar`，≤ 512 MiB）：校验路径与扩展名 → 计算 SHA-256 → 复制到受管暂存 → 原子 rename 到目标目录 → SQLite 索引写入（同事务）；目标处同名文件已存在时拒绝导入且不覆盖；任何失败清理暂存，不留半成品。
4. 启用/停用：通过 `.disabled` 文件后缀切换（游戏忽略该后缀文件），索引与文件状态一致；rename 失败时反向补偿。
5. 按实例与类型的清单查询；实例隔离：资源文件与索引只落在目标实例。
6. schema v12：新增 `instance_resources` 表。
7. 桌面命令与资源中心"资源内容"区：类型分段、原生文件选择导入（tauri-plugin-dialog）、启用开关、数据包目标世界选择。

## 非目标

- 不实现资源内容的删除与回收站扩展（随 M17 截图管理一起设计）。
- 不实现 Modrinth 资源包/光影在线搜索（后续里程碑）。
- 不实现世界存档与截图管理（M17）。
- 不修改游戏 `options.txt`；资源包/光影在游戏内的最终选用仍由用户在游戏中确认，界面明确说明。

## 安全不变量

- 导入不覆盖既有文件；同名拒绝。
- 索引写入失败时必须移除已落位文件，回到导入前状态。
- 启用/停用只通过受管后缀 rename 完成，索引与文件系统观察结果一致。
- 数据包必须装入用户明确选择的世界目录，不允许默认世界。
- 资源文件不进入共享缓存，不跨实例复制。

## 验证

- Rust BDD：三种类型导入与清单、同名拒绝、索引失败回滚、启用/停用与补偿、数据包世界选择校验、实例隔离、schema 迁移。
- Playwright：资源内容区分段、导入流程（mock 路径）、启用开关、数据包世界选择、960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
