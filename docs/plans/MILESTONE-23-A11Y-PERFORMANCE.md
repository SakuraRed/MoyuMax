# 里程碑 23：无障碍增强与性能正式验收

## 目标

用户可以在应用内手动开启减少动画与高对比（不依赖操作系统设置）并持久化；键盘可完成各页面主要任务；冷启动与前台内存按需求书预算给出正式基准结果。

## 范围

1. 减少动画：`ui_motion`（system/reduce）设置；reduce 时经 `data-motion` 属性强制禁用过渡与动画（系统媒体查询已有，本里程碑补手动覆盖）；外观设置区提供开关。
2. 高对比：`ui_contrast`（standard/high）设置；high 时经 `data-contrast` 覆盖变量（加粗边框、强化文本对比、加粗焦点环，独立于系统 forced-colors）；外观设置区提供开关。
3. 键盘与语义：首页主要任务链全部可 Tab 到达且焦点可见；对话框焦点圈定已在 M9 完成，本里程碑以 e2e 锁定。
4. 性能正式基准：release-smoke 扩展 `cold` 模式——进程启动 → 首个窗口可见（目标 P95 ≤ 500 ms）、→ 可操作（P50 ≤ 1 s、P95 ≤ 2 s）、前台进程树私有内存（目标 ≤ 180 MiB、硬上限 256 MiB）；结果写入 output/release-smoke 并记录 eval。
5. 设置持久化：`ui_motion`/`ui_contrast` 进 app_settings（shell.rs 设置族），桌面命令与外观区 UI。

## 非目标

- 不做虚拟化长列表（当前列表规模未触发预算问题）。
- 不做屏幕阅读器全量口述验收（人工验收属发布形成性测试，缺口 #15）。
- 不承诺达成基准设备目标之外的平台性能。

## 验证

- Playwright：减少动画/高对比设置生效并持久化、属性与变量实值、首页 Tab 链路、960×600 与 200% 缩放。
- release-smoke `cold` 模式：冷启动三轮样本与前台内存样本写入报告。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
