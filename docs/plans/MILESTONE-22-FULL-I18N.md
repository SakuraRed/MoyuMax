# 里程碑 22：全页面文案外置

## 目标

在 M21 字典基础设施之上，把剩余页面的全部用户可见文案外置到三语字典，此后任何新文案必须先入字典；界面不再存在硬编码中文文案（品牌名、第三方名称、示例占位与纯数据除外）。

## 范围

1. 组件外置：ResourceCenter、TaskCenter、DataCenter、CrashCenter、GameInstall、Onboarding 的全部用户可见字符串（含 aria-label、placeholder、动态模板静态部分）。
2. 逻辑文案外置：close-flow.ts 退出影响描述、shell-state.ts 可恢复页名（如有文案）、installation.ts/onboarding.ts 中的界面文案（如有）。
3. 字典扩展：新键按既有分层命名加入三语字典并保持三文件键集合一致；Vitest 不变量继续强制。
4. 状态映射集中：任务状态、备份状态、加载器名等枚举到文案的映射统一直接在组件内调用 t()。
5. 回归：M21 已外置页面与全部 e2e 不变。

## 非目标

- 不实现自定义背景、视频/动画背景与第三方主题包。
- 不实现社区语言包加载机制。
- 不改动后端错误文案（核心返回的中文错误属另一层，后续统一决策）。

## 验证

- 静态扫描：组件源码不再出现未豁免的硬编码中文界面字符串（检查脚本或审查清单）。
- Vitest：三语键集合一致、占位符一致。
- Playwright：英文与繁体下各页面关键文案实际渲染为目标语言；960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
