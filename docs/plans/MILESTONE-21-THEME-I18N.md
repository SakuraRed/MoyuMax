# 里程碑 21：主题切换与 i18n 基础设施

## 目标

用户可以在系统/浅色/深色主题之间切换并持久化；界面语言支持简体中文、繁体中文、英文，经统一字典基础设施切换并持久化；本里程碑完成应用壳、首页与设置页的文案外置，为其余页面建立不回头的外置机制。

## 范围

1. 主题：`system`（跟随系统）/`light`/`dark`；浅色变量抽公共选择器；选择持久化到核心 app_settings，启动即生效；动态值只走 CSS 变量，不做命令式样式改写。
2. i18n 基础设施：前端字典模块（zh-CN 为源语言，zh-TW 与 en 缺键回退 zh-CN），`t(key)` 响应式求值；语言持久化到核心 app_settings。
3. 文案外置（本里程碑范围）：应用壳导航与状态栏、关闭对话框、首页、设置页（账户、备份、Java 区）。
4. 设置页新增"外观与语言"区：主题三段选择、语言三段选择，切换立即生效。
5. 核心设置：`ui_theme()`/`set_ui_theme()`、`ui_language()`/`set_ui_language()`（shell.rs 设置族扩展）与桌面命令。

## 非目标

- 不完成其余页面（资源、任务、数据、诊断、安装向导、回收站对话框）的文案外置（M22 继续，机制已就位）。
- 不实现自定义背景、视频/动画背景与第三方主题包（缺口 #9 后半，单独里程碑）。
- 不实现社区语言包（纯数据包机制后续）。

## 安全不变量

- 语言与主题选择只影响呈现层，不改变任何数据或事务语义。
- 主题与语言包禁止远程资源；全部字典内置在构建产物中。
- 缺键必须回退源语言并保证界面不出现空白文本。

## 验证

- Vitest：字典完整性（zh-TW/en 的键 ⊆ zh-CN）、回退、切换。
- Playwright：主题三段切换（CSS 变量实际变化）、语言切换（导航文案实际变化并持久化）、设置区、960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
