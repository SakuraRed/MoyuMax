# 里程碑 9：安装式应用生命周期与托盘快速唤醒

## 目标

MoyuMax 作为安装式常驻应用，首次关闭窗口时让用户在“最小化到托盘”与“退出”之间做知情选择并允许记住；最小化到托盘后销毁重型 WebView 界面，只保留轻量后台核心与托盘图标；托盘提供显示、最近实例快速启动、活动任务摘要、暂停全部任务和始终可用的退出入口；唤醒时快速重建窗口并恢复上次非敏感页面与滚动位置；退出前对运行中游戏和活动任务明确说明影响，确认后安全终止游戏并完成任务后备份，活动下载转为可恢复的暂停状态，不损坏任何受管数据。

## 范围

1. 关闭窗口行为：Rust 侧拦截 `CloseRequested` 并阻止直接关闭，统一转为前端关闭流程；首次关闭弹出一次性选择对话框（最小化到托盘 / 退出 / 记住本次选择）；记住的行为持久化在 SQLite `app_settings`，可选值为 `ask`、`minimize_to_tray`、`exit`，默认 `ask`。
2. 托盘：系统托盘图标（开发占位图标，正式图标属发布缺口 #13）；菜单包含“显示 MoyuMax”、最近实例快速启动（最多 5 个，按最近会话排序，运行中带标记）、活动任务只读摘要（最多 3 条并显示总数）、“暂停全部任务 / 恢复全部任务”、“退出 MoyuMax”；双击托盘图标等同于“显示 MoyuMax”；菜单内容每 3 秒按数据库事实重建。
3. 轻量后台：最小化到托盘先隐藏窗口保留界面（快速唤醒路径，实测 wake→show P95 约 1 ms）；空闲 5 分钟后销毁 `main` WebView 窗口释放内存，仅保留 Rust 核心、SQLite 与托盘（实测后台私有内存约 9 MiB）；再次唤醒按原窗口配置重建 WebView 并恢复焦点（实测重建约 330–350 ms，作为慢速路径记录）。通过 `RunEvent::ExitRequested` 阻止进程随窗口销毁退出。
4. 唤醒恢复：前端把当前页面与主内容滚动位置（去抖后）持久化到 `app_settings`；只有从托盘唤醒重建的窗口（`startup_kind = wake`）才恢复，冷启动始终落地首页或首次引导；未列入可恢复白名单或标记为敏感的页面一律回退首页，弹窗状态不跨唤醒恢复。隐藏保留期间前端暂停 1 秒轮询。
5. 暂停全部任务：全局 `tasks_paused` 设置持久化；暂停时阻止新任务调度，并对执行中的下载做分段级中断（保留已写入的 `.partial` 与校验状态，任务进入 `paused` 而非 `failed`）；已进入校验/提交阶段的任务完成其原子提交。恢复全部时暂停任务重新入队执行。托盘菜单与任务中心展示同一暂停事实。
6. 退出保护：退出前汇总影响（运行中游戏会话、活动安装/内容任务、已暂停任务）；无影响时直接退出；有影响时对话框逐项说明；确认退出时先中断下载（转为可恢复暂停），再请求安全终止游戏会话（沿用 M4 停止通道与 M8 退出后备份），等待会话收敛（上限 120 秒）后退出；超时给出“强制退出”选择并说明备份可能未完成。
7. 启动不阻塞：托盘构建只涉及本地资源；首个可交互窗口不被托盘初始化、任务恢复检查或未来的更新检查阻塞（更新检查本身属后续里程碑）。
8. 性能验证：提供 `MOYUMAX_SMOKE` 环境变量门控的最小化→唤醒自动序列与 `scripts/release-smoke.mjs` 驱动，分别采样快速唤醒（隐藏后显示）与慢速唤醒（销毁后重建）耗时，以及 WebView 销毁后的后台私有内存，验证快速唤醒 P95 ≤ 250 ms、销毁后后台私有内存目标 ≤ 80 MiB、硬上限 120 MiB。

## 非目标

- 不实现开机自启动与“启动到托盘”设置项；与设置页一同在后续里程碑交付。
- 不实现单任务暂停/恢复、优先级、限速与压力感知并发（属任务控制里程碑）；本里程碑只有全局暂停/恢复。
- 不实现更新检查、下载与安装本身；只保证其未来入口不阻塞首窗。
- 不实现账户、密码保险库等敏感明文页面；唤醒重遮罩以页面注册表机制固定，待账户里程碑接入真实敏感页面。
- 不交付正式应用图标、Authenticode 或安装器图标变更。
- macOS/Linux 生命周期不在本里程碑验证范围。

## 安全不变量

- 任何关闭路径（自定义标题栏、Alt+F4、托盘退出）都必须经过同一影响检查，不允许绕过。
- 退出确认前不得终止游戏或取消任务；用户取消退出后运行状态保持原样。
- 下载暂停只丢弃未提交的响应流；已写入暂存的 `.partial`、共享缓存与实例数据不得删除或损坏。
- 暂停状态持久化，重启后保持暂停，不自动恢复下载。
- 托盘菜单与窗口界面展示的任务、实例事实必须来自同一 SQLite 查询，不允许两份状态。
- 托盘脚本、更新检查与后台循环不得向公网发起任何请求；默认离线语义不变。
- 恢复上次页面时，未在白名单内的页面或敏感页面必须落到首页，且任何弹窗不自动重开。

## 验证

- Rust BDD（`tray_lifecycle_bdd.rs`）：关闭行为读写与默认值、壳层状态持久化与敏感回退、暂停状态迁移与重启保持、下载分段中断保留 `.partial` 并从中断处续传、退出影响汇总、最近实例排序。
- 桌面单元测试：托盘菜单模型构建（空态、实例运行标记、任务摘要截断、暂停/恢复切换）、窗口重建配置、退出编排状态机。
- Vitest：关闭决策状态机、壳层状态白名单/敏感回退、去抖持久化。
- Playwright：首次关闭对话框（选项、记住、焦点、Esc）、记住后不再询问、退出影响对话框、唤醒页面与滚动恢复、敏感回退、960×600 与 200% 缩放。
- Release 冒烟：`MOYUMAX_SMOKE` 序列 + `scripts/release-smoke.mjs` 输出唤醒耗时与后台私有内存样本，写入 `output/release-smoke/`。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产 Web 构建与 NSIS 构建通过。
