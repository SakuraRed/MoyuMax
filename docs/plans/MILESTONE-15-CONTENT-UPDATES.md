# 里程碑 15：Modrinth 全加载器与按实例更新策略

## 目标

Quilt、Forge、NeoForge 实例获得与 Fabric 一致的 Modrinth 搜索、依赖解析与原子安装能力；用户可以按实例检查模组更新、查看变更并选择逐项或全部更新，更新前先创建恢复点，失败时完整回滚到更新前状态。内容自动更新默认关闭，按实例开启后也只提供用户明确触发的更新路径。

## 范围

1. 解除 Modrinth 安装的 Fabric 限制：加载器集合为 fabric/quilt/forge/neoforge；Modrinth 兼容过滤继续按实例加载器。
2. 更新检查：按实例解析已安装内容的最新兼容版本，输出逐项更新清单（当前版本 → 最新版本）；默认只提示，不下载。
3. 更新执行：更新计划携带 `is_update` 标记，允许同名异哈希替换；替换前把旧文件移入实例快照区（`.moyumax/snapshots/content-update-{task}/`），任何失败回滚到更新前状态；中断任务在重启后自动恢复旧文件再进入恢复确认。
4. 按实例自动更新策略：持久化开关，默认关闭；开启后更新入口提供“全部更新”，但更新仍需用户明确触发，不做静默后台修改。
5. schema v11：实例表增加内容自动更新开关列。

## 非目标

- 不实现按内容锁定/忽略更新（已有字段保留语义，后续里程碑接入界面）。
- 不实现资源包/光影/数据包/世界/截图管理与运行期间增量备份（M16/M17）。
- 不实现 CurseForge 目录。

## 安全不变量

- 更新替换必须先备份旧文件；任何下载、校验、数据库或发布失败都完整回滚到更新前状态。
- 更新检查不下载内容文件，不产生任务。
- 默认关闭时不做任何修改；开启自动更新也不静默修改实例。
- 加载器兼容过滤按实例真实加载器，不得放宽到不兼容版本。

## 验证

- Rust BDD：Quilt/Forge/NeoForge 实例模组安装、更新检查清单、更新替换带备份、失败回滚、中断恢复旧文件、策略默认关闭不下载。
- Playwright：资源中心更新清单、逐项/全部更新、自动更新开关、960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
