# 里程碑 5：Modrinth 模组与依赖事务

## 用户结果

用户从资源页为一个已安装 Fabric 实例搜索兼容模组。确认页清楚列出目标模组、自动加入的必需依赖和未默认选中的可选依赖。所有文件经校验后作为一个事务进入实例；任何失败都不会留下半套依赖或覆盖用户已有文件。

## 实现范围

1. 独立 `ModrinthProvider`，使用官方 API v2、唯一 User-Agent、超时、限流信息和可替换测试基址。
2. 按目标实例构造搜索 facets，长期保存项目与版本 ID，不加载远程图片。
3. 精确选择兼容版本和主文件，拒绝 sources JAR 与未列出版本。
4. 递归解析 required、optional、incompatible 和 embedded 依赖，检测循环、去重并稳定排序。
5. 下载文件时验证大小、SHA-1 和 SHA-512；复用已有并发、续传和来源校验能力。
6. 在统一任务协调器中执行内容任务，文件发布和 SQLite 索引具备补偿回滚。
7. `installed_content` 记录来源、项目、版本、文件、哈希、启用状态和更新策略；本地管理不依赖网络。
8. Tauri 只适配搜索、预览、确认和任务命令；Svelte 资源界面保持声明式并覆盖空、加载、结果、确认、进度、失败和离线状态。

## 不变量

- 不擅自安装用户未选择的目标模组或可选依赖。
- 必需依赖不能被静默省略；无法解析时阻止安装并解释。
- 任何文件进入实例前必须验证可信哈希和大小。
- 同名异哈希文件不得被覆盖；已有用户内容保持原样。
- 网络错误、限流和 provider 退役不得影响本地内容列表与游戏启动。
- 内容自动更新默认关闭，本里程碑不后台修改实例。
- 不记录令牌，不引用远程图片，不执行模组附带脚本。

## 真实验收

在保留的 Minecraft 26.2 Fabric 实例上，从官方 API 动态解析 Continuity 及其 required Fabric API 依赖，完成下载、双哈希校验、原子发布和数据库索引。随后启动游戏，确认 Fabric Loader 同时发现两个模组；回滚测试确认任一文件冲突时两个文件都不改变。

## 实现状态

2026-07-23 已实现并验证：

- Modrinth 搜索、版本选择、主文件选择与依赖闭包解析。
- SHA-1、SHA-256 与 SHA-512 通用下载校验，内容共享缓存和受管暂存区。
- `content_install_tasks`、`content_task_progress` 与 `installed_content` 持久化索引。
- 同名异哈希阻断、数据库失败补偿回滚和崩溃提交日志恢复。
- 游戏安装与内容安装共用单一后台任务槽。
- 声明式资源页、可选依赖确认、统一任务中心和本地离线内容列表。
- 官方 Continuity 与 required Fabric API 在实例副本中的真实安装和真实启动。
