# 里程碑 7：实例内置回收站与恢复

## 目标

用户可以从首页将未运行的实例移入 MoyuMax 完全本地的内置回收站，在数据页查看名称、占用空间和 30 天保留期限，并恢复到原位置。永久删除必须经过包含对象数量、空间和不可恢复说明的二次确认。实例删除与恢复均不删除托管 Java 或共享基础文件。

## 范围

1. SQLite 新增回收站操作记录，保留对象类型、实例标识、原位置、回收位置、原状态、占用空间、删除时间、到期时间和事务状态。
2. 实例目录只允许从受管 `instances` 根移动到同一数据位置内的受管回收站；不跟随符号链接计算内容，不接触共享仓库或 Java 目录。
3. 回收、恢复和永久删除采用持久化状态机；启动时收敛中断的移动、恢复或删除操作。
4. 正在运行的实例拒绝回收；恢复位置存在内容时拒绝覆盖。
5. 实例处于回收站期间保留运行时、内容和历史索引；恢复后继续复用原 Java。
6. 首页提供“移入回收站”确认；数据页覆盖空状态、列表、恢复、永久删除确认、处理中和失败状态。
7. 浏览器运行时提供等价的本地确定性模型，用于声明式 UI 与无障碍 E2E。

## 非目标

- 本里程碑不自动清理到期项目，也不在空间不足时擅自删除内容。
- 世界级单独回收、备份时间线、迁移和按需清理到目标空间由后续里程碑完成。
- 不删除托管 Java、共享游戏基础文件或诊断导出。

## 安全不变量

- 未经用户确认不移动实例；未经第二次明确确认不永久删除。
- 正在运行的实例、受管根以外的目录和恢复位置冲突均拒绝操作。
- 回收失败必须保留一个可恢复副本，不得覆盖原位置或无提示丢失索引。
- 永久删除实例后 Java 记录和 Java 目录继续保留。

## 验证

- Rust BDD 覆盖删除恢复、运行中拒绝、位置冲突、永久删除、Java 保留和中断恢复。
- Playwright 覆盖首页确认、数据页恢复、永久删除风险确认、键盘语义和 200% 缩放。
- 全工作区 Rust 测试、Clippy、格式检查、Svelte 检查、Vitest、Playwright 和生产构建通过。
