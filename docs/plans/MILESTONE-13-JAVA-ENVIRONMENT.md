# 里程碑 13：Java 环境管理与删除/恢复闭环

## 目标

高级用户可在设置页查看全部托管 Java 环境（发行版、完整补丁版本、架构、位置、大小、健康状态、引用实例），执行验证、设为实例环境、打开位置与删除；删除仍被引用的环境时必须展示受影响实例并确认风险；实例启动时环境缺失给出明确恢复路径——一键恢复（用户主动触发，获取同线最新补丁）或为实例选择其他环境，绝不自动装回用户删除的构建。普通用户的默认安装路径不受影响。

## 范围

1. 核心：环境清单查询（含大小、健康、引用实例）、`deleted` 墓碑状态、删除（引用时需确认）、健康验证、设为实例环境（校验主版本一致并同步数据库与磁盘运行时清单）、一键恢复（解析同线最新补丁并更新引用）、启动时环境缺失的明确错误。
2. 删除只移除受管目录内文件，墓碑保留身份与引用；应用重启后收敛中断的删除。
3. 新安装计划：墓碑身份不被复用；显式新安装可重新下载同一身份（用户主动发起的新任务）。
4. 设置页骨架：导航“设置”启用，当前只承载 Java 环境组；其他设置分组随各自里程碑进入，不放占位。
5. 环境组界面：列表、健康/大小/引用、验证、设为实例环境、打开位置、删除（含引用确认对话框）、已删除区与一键恢复。

## 非目标

- 不实现其他设置分组（通用、下载、来源、外观、无障碍、开发者、关于）。
- 不实现手动导入系统 Java；托管发行版仍为 Azul Zulu。
- 不改变 M2 自动选择与去重语义、不改变默认安装流程。

## 安全不变量

- 删除只清理受管数据目录内的环境文件，不触碰系统 Java 与实例数据。
- 删除被引用环境必须列出受影响实例并经确认；墓碑不自动清理。
- 设为实例环境必须主版本一致；数据库与磁盘运行时清单同步更新，不一致时启动拒绝。
- 环境缺失的实例启动必须明确报错并指引恢复，不得静默重装。

## 验证

- Rust BDD：清单与引用、删除需确认、墓碑保留、重启收敛中断删除、设为实例环境（含主版本不一致拒绝与磁盘同步）、恢复更新引用、启动缺失报错。
- Playwright：环境列表、引用删除确认、恢复入口、设为实例环境、960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
