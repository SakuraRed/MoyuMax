# 里程碑 18：截图管理与删除回收站统一

## 目标

用户可以按实例浏览截图、筛选、复制到剪贴板、打开本地位置；截图、资源内容（M16）与世界（M17）的删除全部进入与实例相同的回收站事务模型，30 天保留、可恢复、可永久删除，重启后收敛中断操作。

## 范围

1. 截图清单：扫描实例 `.minecraft/screenshots/*.png`（文件名、大小、修改时间）；筛选支持全部/本周。
2. 截图复制：图片解码后写入系统剪贴板（tauri-plugin-clipboard-manager）；打开本地位置使用系统文件管理器选中文件。
3. 统一删除回收站：`RecycleItemKind` 扩展为 instance/screenshot/resource/world；三类删除与实例共用 intent → rename → finalize 事务、失败补偿与重启收敛；schema v13 为回收站项目增加 `payload` 列（资源索引行 JSON，恢复时无损重建）。
4. 删除入口与确认：截图区、资源中心资源行、数据中心世界行均提供删除，先经确认对话框说明可恢复性；停用状态的资源按 `.disabled` 实际文件名处理。
5. 恢复与永久删除：非实例项目经 `restore_recycled_entry` 恢复原位置（被占用则拒绝，不覆盖）；永久删除对所有类型开放；回收站列表按类型标注。
6. 前端：数据中心新增截图区（实例选择、网格、筛选、选中操作条）；回收站支持全类型恢复与清理。

## 非目标

- 不实现按世界筛选截图（截图文件名不含世界信息，无法可靠归属）。
- 不实现实例回收站到期自动清理（沿用既有手动语义）。
- 不实现视频或其他媒体管理。

## 安全不变量

- 删除一律先进回收站，不做直接永久删除；永久删除必须用户逐项确认。
- 恢复不得覆盖既有文件；原位置被占用时拒绝。
- 资源删除的索引行与文件在同一事务语义下删除与恢复，不允许只有一边。
- 复制只读截图文件；打开位置不执行文件内容。

## 验证

- Rust BDD：截图清单、三类删除进回收站、恢复（含占用拒绝与资源行重建）、永久删除、重启收敛、payload 往返。
- Playwright：截图网格与筛选、选中操作条、删除确认、回收站类型标签与恢复、960×600 与 200% 缩放。
- 全工作区 Rust、Clippy、格式、Svelte、Vitest、Playwright、生产构建与 NSIS 构建通过。
