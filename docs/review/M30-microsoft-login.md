# M30 Microsoft 设备码登录 — 人工审查清单（0.1.0-preview.1）

构建：`D:\downloads\MoyuMax_0.1.0-preview.1_x64-setup.exe`（自签名开发证书，仅本机已信任；
SmartScreen 提示"未知发布者"属预期，选择"仍要运行"）。

自动化已覆盖的部分（可抽查，不必逐项重复）：Rust 190 项（含 msauth_bdd 10/10）、
Playwright 114/114（含 microsoft-login 4/4）、三语键一致、960×600/200% 无溢出。

以下条目需要真实 Microsoft 账户与真实网络，自动化无法覆盖，请逐项人工验证。
完成一项勾一项；发现问题在条目下记录现象与截图位置。

## 1. 真实设备码登录（主链路）

- [ ] 打开 设置 → 账户，点击「添加 Microsoft 账户」
- [ ] 设备码面板出现：8 位用户码、`https://www.microsoft.com/link`、
      「复制用户码」「打开链接」「取消」三个按钮
- [ ] 点击「复制用户码」按钮变为「已复制」，剪贴板内容与面板一致
- [ ] 点击「打开链接」系统浏览器打开 microsoft.com/link（https）
- [ ] 在浏览器输入用户码并登录**已购买 Minecraft 的 Microsoft 账户**
- [ ] 面板在数秒内自动关闭，账户列表出现该 Xbox 玩家名，类型标记
      「Microsoft」，提示「账户已登录，令牌仅保存在本地」
- [ ] 该账户自动成为默认（如列表原本为空）

## 2. 取消与失败路径

- [ ] 再次点击「添加 Microsoft 账户」，面板出现后点「取消」，面板关闭，
      不产生新账户，无错误提示
- [ ] 再次发起，在浏览器页面直接关闭标签页不授权：面板保持等待；
      约 15 分钟后设备码过期（可跳过长时间等待，记录未验证即可）
- [ ] （可选，需小号）用**未购买 Minecraft** 的 Microsoft 账户完成授权：
      面板关闭，顶部出现「该 Microsoft 账户未拥有 Minecraft」可读错误，
      账户列表不新增
- [ ] （可选）用**没有 Xbox 档案**的新 Microsoft 账户授权：出现
      「请先在 xbox.com 创建」提示

## 3. 会话刷新与启动

- [ ] 对该 Microsoft 账户点「刷新会话」，提示「会话已刷新」，状态保持有效
- [ ] 将 Microsoft 账户设为默认，启动一个已安装的实例：游戏正常进入主菜单
- [ ] 在游戏内 多人游戏 → 添加一个正版验证服务器（如 Hypixel）：
      可以正常加入（证明 msa 令牌被真实接受）
- [ ] 断网后点「刷新会话」：出现网络错误提示，账户状态不被误标为已过期

## 4. 令牌保密

- [ ] 诊断 → 导出诊断包，解压后全文搜索玩家名与邮箱：不出现任何令牌串
- [ ] 账户列表、事件提示中均不显示令牌内容

## 5. 界面与文案

- [ ] 切换到 English：设备码面板按钮、等待提示、错误文案均为英文
- [ ] 切换到繁體中文：文案为繁体
- [ ] 窗口 960×600 并将系统缩放设为 200%：账户区与设备码面板无横向滚动条
- [ ] 高对比模式开启时面板按钮边界清晰可辨

## 6. 安装包与签名

- [ ] 右键安装包 → 属性 → 数字签名：存在「MoyuMax Dev Signing」签名，
      本机显示「此数字签名正常」
- [ ] 安装后 设置 → 关于：版本 0.1.0-preview.1，声明显示「自签名开发预览构建」
      （不再是「未签名」）

## 已知边界（非缺陷，无需报告）

- 其他机器安装会提示未知发布者（自签名证书仅本机信任，正式版需商业证书）
- 「打开链接」在系统默认浏览器打开，不支持应用内嵌登录（有意设计）
- 设备码有效期约 15 分钟，超时需重新发起
